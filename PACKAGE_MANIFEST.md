# Source Package Manifest

The exported archive is intentionally limited to the Python MVP and its documentation. It excludes the unrelated web-template client, package-manager caches, local SQLite databases, prepared media, encryption keys, runtime logs, virtual environments, and generated bytecode.

| Archive path | Contents |
| --- | --- |
| `README.md` | Package overview, installation, component map, and evidence boundaries. |
| `python_service/audio_streaming/` | FastAPI service, authorization/capability helpers, SQLite repository, media preparation, HLS encryption/playlist code, watermark DSP, bounded cache/pool controls, enhancement DSP, and studio-mastering DSP. |
| `python_service/tests/` | API security, HLS encryption, attribution, watermark fixture/boundary, concurrency, and enhancement regression tests. |
| `python_service/README.md` | Streaming API, operational model, HLS encryption, deployment, capacity, rotation, and threat documentation. |
| `python_service/README_ENHANCER.md` | Enhancement algorithm, invocation, behavior, and quality-evaluation limits. |
| `python_service/README_MASTERING.md` | CPU-only studio-mastering chain (EQ, de-esser, multiband compression, saturation, LUFS, true-peak limiting) and its honest scope boundary. |
| `python_service/README_PIPELINE.md` | One-call enhance-then-master pipeline: auto noise-reduction (VAD-gated) + mastering, and its decision guard. |
| `python_service/audio_streaming/enhance.py` | Single `POST /v1/enhance` HTTP endpoint: decodes uploaded audio, runs the full pipeline, returns processed audio + report. |
| `python_service/tests/test_enhance_endpoint.py` | End-to-end tests for `POST /v1/enhance` (auth, mp3 round-trip, noise detection, bad-payload rejection). |
| `python_service/requirements.txt` | Pinned Python runtime and test dependencies. |
| `python_service/Dockerfile` | Reference container image for an external production container platform. |
| `docs/research_notes.md` | Architecture research notes and cited source links. |

The package contains no application secret, user data, source audio, generated encrypted segment, raw key, runtime database, or performance claim. It is source code for review and deployment preparation, not a claim of production-scale capacity or a watermark-robustness certification.
